# Elevvo Frontend Development — Module 5

## Responsive Hero Section with Tailwind CSS

### 📌 Project Overview

This project is part of the Elevvo Frontend Development Internship. It focuses on building a clean, modern, and responsive hero section using **Vite, JavaScript, and Tailwind CSS**.

The hero section introduces frontend development with a heading, a short description, and a call-to-action button. Tailwind CSS utility classes are used to manage the layout, typography, colors, spacing, and responsive behavior.

### 🎯 Project Objective

To learn how to set up a Vite project, integrate Tailwind CSS, use utility-first styling, and create a responsive hero section while practicing Git branching, merging, and GitHub version control.

### ✨ Core Features

- Responsive hero section for different screen sizes.
- Modern dark background with purple accent colors.
- Clear heading and descriptive text.
- Call-to-action button with a hover effect.
- Responsive typography and spacing using Tailwind CSS.
- Fast development environment powered by Vite.

### 🛠️ Technology Stack

- **HTML5** — Page structure.
- **JavaScript** — Dynamic rendering of the hero section.
- **Tailwind CSS v4** — Utility-first styling and responsive design.
- **Vite** — Development server and build tooling.
- **Git and GitHub** — Version control and project hosting.

### 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/Adeeba333/Elevvo_Frontend_Development_mod5.git
```

**2. Navigate to the project folder**

```bash
cd Elevvo_Frontend_Development_mod5
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in the terminal to view the project in your browser.

### 📚 Key Learnings

- Setting up a frontend project with Vite.
- Installing and configuring Tailwind CSS with the Vite plugin.
- Applying utility classes for responsive layouts and styling.
- Using Git branches and merging feature changes into the main branch.
- Pushing project updates to GitHub.
